# Simple Calculator

This project is a lightweight, responsive calculator built with plain HTML, CSS, and JavaScript. It demonstrates basic arithmetic operations, a clean UI, and smooth interactions.

## Features
- Basic arithmetic: addition, subtraction, multiplication, division.
- Clear button to reset the calculator.
- Responsive design that works on mobile and desktop.
- Smooth button transitions and a modern gradient background.

## Setup & Usage

1. **Clone the repository** (or download the files).
2. **Open the calculator**:
   - No build step is required. Simply open `frontend/index.html` in your browser.
   - If you prefer a local server, you can run:
     ```bash
     npx serve frontend
     ```
     or any other static file server.

## File Structure

- `frontend/index.html` – Main HTML file containing the calculator layout.
- `frontend/style.css` – CSS file defining the visual style of the calculator.
- `frontend/script.js` – JavaScript file implementing calculator logic.
- `frontend/README.md` – Documentation for the project.

## Customization

Feel free to tweak the styles in `style.css` or extend the functionality in `script.js`. The code is intentionally simple to serve as a learning reference.
