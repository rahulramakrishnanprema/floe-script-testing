# Advanced Calculator (Frontend)

## Overview
This project is a simple yet powerful calculator built with React, Vite, and Tailwind CSS. It demonstrates modern frontend tooling and a clean component architecture.

## Prerequisites
- Node.js (v18 or newer)
- npm (v9 or newer)

## Setup
```bash
# Clone the repository
git clone <repository-url>
cd <repository-folder>/frontend

# Install dependencies
npm install
```

## Running the Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173` (or the URL shown in the terminal).

## Building for Production
```bash
npm run build
```
The production build will be available in the `dist` folder.

## Previewing the Production Build
```bash
npm run preview
```

## Project Structure
- `src/components/Calculator.jsx` – Main calculator logic and state.
- `src/components/Display.jsx` – Shows the current input and result.
- `src/components/Button.jsx` – Reusable button component.
- `src/components/ButtonGrid.jsx` – Layout of all calculator buttons.

Enjoy building and extending the calculator!
