# Frontend

## Prerequisites
- Node.js 20.x or newer
- npm 10.x or newer

## Setup
```bash
npm install
```

## Development
```bash
npm run dev
```
The app will be available at `http://localhost:5173`. It proxies API requests to the backend running on `http://localhost:8000`.

## Build
```bash
npm run build
```
The production build will be in the `dist/` folder.

## Preview
```bash
npm run preview
```
